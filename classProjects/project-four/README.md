# Prolog: Creating a database and rules describing The Simpsons family and relations

About the Simpsons family tree from the show The Simpsons. Don't have all the characters names. There's a picture of the Simpsons family tree in this folder to see the characters. Using Prolog, you can use the queries to prompt in the console. Like "is_sibling( bart, lisa).", asking is Bart a sibling of Lisa. It will return "bart is a sibling of lisa". With the queries, if something is false. It will return with the false statement. "is_sibling( zia, jiff).", returns "zia is not a sibling of jiff". Added a second family, Griffin family from Family Guy. There is a picture of their family tree in this folder for references.

# Queries & Questions
Again, there are queries in the family_queries file. To call it, type in the console of your choice. Some queries/questions require parameters. Example: "is_related( bart, lisa)", asking and printing if bart and lisa are related. These will still print even if they are false. There are queries/questions that don't require parameters. Example: "count_adults", counting and printing how many adults.
